Funcionalidades:
ira aparecer um meno no terminal e o usuario devera escolher entra as opções disponiveis:

1 - Adicionar livro (em memória)
2 - Buscar livro por código
3 - Imprimir todos os livros cadastrados
4 - Ordenar livros por ano e imprimir
5 - Encerrar o sistema

Estrutura dos dados:
cada livro é representado por um struct que contem:

int codigo
char titulo[50]
int ano
int quantidade
